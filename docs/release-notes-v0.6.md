# YotaPaper v0.6

> 合并上游 PR #4：控制中心界面优化与功能增删。

## 控制中心面板改版

- 顶部信息区重做：时钟 + 日期 + 充电标识 + 电量进度条与百分比。
- 快捷按钮栏：**飞行模式** / **设置**（顶部齿轮直达设置页） / **全刷**（手动 EPD 全刷） / **锁定**（静默锁屏）。
- WiFi / 蓝牙保留单击开关 + 长按进入系统设置，状态副标题实时刷新。
- 音量改为滑杆 + 百分比显示；移除原「省电模式」按钮。

## 新增：EPD 刷新卡片（可在设置中关闭）

- 显示**当前前台应用名**，就地切换「高画质 / 流畅 / 动画」三种刷新模式。
- 切到「动画」模式时提示「需重启应用生效」，并提供「立即重启」按钮。
- 内置参数滑杆：对比度、锐化、黑拉伸、白拉伸、亮度，拖动即调，松手保存并下发到系统。
- 新增设置项「控制中心 → EPD刷新卡片」开关（默认开）。

## 新增：触摸震动开关

- 新增设置项「控制中心 → 触摸震动」（默认开）；关闭后禁用系统触感反馈，墨水屏操作更安静。

## 稳定性修复

- **预热 Root Shell**：桌面启动后在后台线程预建 libsu 全局 shell，避免重启后首次在控制中心点击「飞行模式」时在主线程创建 root shell 导致阻塞 / ANR。
- 灭屏时重置面板状态（`isPanelActive = false`），避免灭屏后手势状态错乱。

## 新增图标

- `ic_airplane_mode_on`、`ic_airplane_mode_off`、`ic_settings_gear`。
